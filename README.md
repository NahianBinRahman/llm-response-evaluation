# 🧠 LLM Response Evaluation for Food Delivery Customer Support

## 🎯 Objective
This project evaluates and compares AI-generated responses (ChatGPT vs Claude) across real-world customer support scenarios in the food delivery domain.

The goal is to identify which model provides more useful, clear, and actionable responses.

---

## 🧩 Project Overview
- Compared responses from multiple LLMs  
- Selected the best response based on defined criteria  
- Identified issues in weaker responses  
- Provided structured reasoning for each evaluation  

---

## 📊 Evaluation Criteria
Responses were evaluated based on:

- Accuracy  
- Clarity  
- Completeness  
- Tone  
- Usefulness  

---

## ⚠️ Common Issues Identified
- Too vague responses  
- Missing resolution steps  
- Lack of context  
- Unclear or incomplete answers  

---

## 📁 Dataset
- Realistic food delivery customer support scenarios  
- Includes multiple AI responses per scenario  
- Contains:
  - Best response selection  
  - Issue identification  
  - Reasoning for decisions  

---

## 🔍 Key Insights
- High-quality responses include clear solutions and next steps  
- Polite responses are not always useful  
- Detailed and structured answers improve user satisfaction
